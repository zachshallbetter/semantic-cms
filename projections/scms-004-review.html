1

The three roots

titan-node is the GPU host's shell-first control plane: a titan.sh dispatcher over two canonical JSON registries (21 runtimes + 2 credential-holding brokers; a protocol matrix with smokes, bridge profiles, and consumer smokes), preflight discipline, and 17 bridge profiles rendering the fleet into consumer-shaped env contracts. Its authority ranking is explicit and three-tier: running host > canonical files > prose — "deployed reality ≠ docs ≠ canonical source — they drift constantly."

titan-observatory is a 197-line SSH-polling dashboard whose one novel layer is editorial metrics — named load bands with prose that says what not to conclude ("utilization is below max because these jobs are light, not because the node is failing").

Tools is ~40 independent projects. The CMS-relevant core: agent-control-plane (now governing our tickets), open-knowledge (GPL-3 CRDT knowledge base — a working preview of four of our planes), imagetracer and graphify (identity/graph machinery), text-diff-tool, markdown-native-editor, reference-detective, Context Mend's interaction contracts, AntiRepoThreat + inspectors (supply-chain gating), and stitch-skills/design.md (capability packaging and the lock format). Several projects are not what their names suggest; two are empty stubs.

2

Verdict summary

ACP is the work-governance spine — and it's yours

Apache-2.0, zero-dependency, deployed (Railway acp-gateway). Five typed decisions, closed issue packets, a five-tier evidence ladder, approval provenance grades, degraded ≠ paused operating modes. The gateway is the credential-isolation pattern: agents read Project state without ever holding a token.

open-knowledge previews the collaboration core

Y.Text-as-canon, an append-only shadow-git journal with a writer-ID taxonomy, reconciliation with refused as a bounded outcome, layered-liveness presence, warnings on success envelopes. GPL-3 forces a process boundary: consume as a service, never link.

Identity discipline gets its refinements

Two-tier structural/contract hashing, metadata-stripped semantic hashes, domain separation, quantize-before-hash, dual staleness axes — §3.3 of the design upgrades from "canonical hash" to a real identity policy.

The dependency doctrine gains enforcement

Its lock format exists ({source, sourceType, computedHash}), its admission tooling exists (history-resident supply-chain scanning, convergent-evidence scoring), its worked example exists (titan-node's patches-as-receipts) — and its first violation was found (blender-mcp's permanent fork).

Observation gains battle-derived patterns

private_expected as a severity, next_action on every finding, edge-triggered alerting, reference-fingerprint drift, declared-kind vs deployed-artifact checks, consumer-supplied qualification evidence.

One cautionary tale, uniform across all roots

A declaration format richer than the checker that consumes it silently becomes decoration — inert smoke declarations, forked port maps, specs that don't compile. P27 proposes declaration-consumer parity as a gate.

Findings by plane

Cconfirms the design Bbetter mechanism Nnovel, applicable

CBCanon

  • Two-tier identity (imagetracer): geometry_hash over canonical rings; payload_hash over the contract subset. "Did the content change" and "did the rendering agreement change" get different hashes — presentation churn stops invalidating content-keyed caches. The code rule: "Never recompute rings from path_d. Never hash path_d" — hash the source, never the projection.
  • Semantic content hashing (graphify): frontmatter stripped before hashing — reviewed: true must not invalidate every rendering. Hashes domain-separated (\x00) and bound to relative paths.
  • Two independent staleness axes: cheap (ast_hash) and expensive (semantic_hash) derivations invalidate separately, in namespaced caches.
  • Quantize before hashing continuous metrics (fingerprint's bucket_value); its date-keyed HMAC is identity that expires by construction — wrong for Canon, right for presence.
  • Self-describing journal records (open-knowledge): JSON commit trailers carry actor/contributors/checkpoint; a writer-ID taxonomy separates humans, agents, services, and upstream authors at the ref level; rename chains anchored in the record so derived indices rebuild from the journal alone.
  • A declared loss hierarchy: malformed decorative fields drop individually; "decorative loss is preferable to attribution loss."
  • Evidence inside the hashed artifact (imagetracer): coded validations[] ship in the content-addressed payload — qualification cannot desynchronize from content.

CBNContracts

  • ACP's authorization boundary: a closed issue packet (additionalProperties: false), five typed decisions, content-addressed decision IDs (replay-stable), a scope audit diffing changed files against authorized_paths/exclusions, and one Controller allowed to merge.
  • Operating modes with degraded ≠ paused: rate limits degrade (work continues without authority); authorization failures pause ("require correction rather than waiting"). continuation lets reversible work finish on a valid lease during an outage — authority decays gracefully. BLOCKED is productive: resolve the named blocker, resubmit the same packet.
  • Authority with expiry and reversal (Context Mend): capabilities expire ≤30 days; expiry fails closed and resumes what it had suspended.
  • Plan identity with an exclusion list: time, randomness, iteration order, and display strings are named as excluded from identity — what makes a frozen plan re-verifiable.
  • Cross-repo contract verification (titan-node): the provider asserts the consumer's committed contract field-by-field — contracts checked from both sides.

Silence, a repeated "continue," a green local test, or a browser session is not approval.

agent-control-plane · operating model

CBNQualification

  • The five-tier evidence ladder: Documented ≠ Implemented ≠ Tested ≠ Deployed ≠ Browser-verified, no lower tier satisfying a higher requirement — adds the delivery distinction our four-tier ladder lacks.
  • Approval provenance grades: self-approved vs independent-approved, never interchangeable. "Human approved" is not a boolean.
  • private_expected (titan-node): a 401 from a gated surface is correctly refused — positive evidence, neither pass nor fail. Every finding carries next_action: machine-readable remediation in the schema.
  • Consumer-supplied evidence: the provider's gate runs the dependent's test suite in the dependent's checkout — readiness attested by consumers, not self-attested.
  • Calibrated evidence (reference-detective): quote-anchored typed signals; taxonomyVersion on every inference (find stale inferences when the vocabulary moves); otherProbabilityMass reserving posterior mass for unmodeled hypotheses; entropy as a self-reported "I don't know"; contradiction pairs as a model-free hallucination tripwire; sanitization that counts what it dropped.
  • Provenance-typed confidence (graphify): EXTRACTED / INFERRED / AMBIGUOUS answers how do we know — with the anti-pattern documented next door (a float measuring input completeness and calling it confidence).
  • The claim register (Context Mend): every claim the system makes about itself, its admissible status, and the evidence that would strengthen it — qualification for self-description.

CBProjection

  • Round-trip fidelity as a tested contract (markdown-native-editor): serialize(parse(md)) === md with corpus goldens, a benchmark gate, and a declared stable/in-progress matrix — a rendering is legitimate only if it inverts. Its 237-line MIT markdown-core is the liftable artifact.
  • Y.Text-is-truth (open-knowledge): raw user bytes are canon; the rendered fragment is derived; both updated atomically — the dynamic twin of the round-trip invariant.
  • The decision-free renderer (layoutmaterialization): "a dumb renderer… makes NO geometric decisions" — our projection purity contract, independently derived.
  • Compiled context with freshness as admission (ACP .llms/): per-file SHA-256 manifest; a stale corpus is a hard BLOCKED.
  • Preserve-lists on destructive projection (titan-node sync): mirror aggressively, protect locally-owned facts.

CNField & Observation

  • Metrics shipped with misreading guards (titan-observatory): named bands plus prose stating what not to conclude; predicted-vs-actual budget deltas as a calibration metric (token-optimizer).
  • Edge-triggered observation (titan-node): notify on OK→FAIL/FAIL→OK transitions against persisted state — a drift event log, not a poll log.
  • Reference-fingerprint drift: one artifact is the reference; hash everything against it — fleet-wide consistency without centralizing the value.
  • Five observation states (Context Mend): measured / disabled / unavailable / unsupported / stale — three different silences most systems collapse — plus "no non-measured state may be converted to a plausible value."
  • Layered liveness with a stated primary (open-knowledge): WS-close authoritative, TTLs as belt-and-suspenders; 'writing' ≠ 'editing' — presence distinguishes actor kinds.
  • Absence encodings enforced: [] as a positive assertion vs undefined as absence of evidence; an errored list refuses to return empty because that is byte-identical to "no conflicts."
  • The negative example (titan-observatory): real provenance but no staleness disclosure — a dead SSH path renders identically to a healthy idle fleet. Cite it in the provenance-chip spec.

Realtime obligations

  • R1: merge as a serializable decision map (Map<hunk, accept|reject|keep>) — replayable, diffable, attachable to Canon as the merge's justification; refused as a bounded reconcile outcome; conflict shapes selecting legal strategies; reconcile against the live view, not disk. The named negative example: debounced full-content last-write-wins with no CRDT (wysiwig-editor).
  • R3: warnings on success envelopes — "the write landed and diverged," with converged bytes inline for recovery; honesty channels grouped by remedy, not severity. Our Contracts plane needs the accepted-with-disclosed-anomaly outcome class.

Housekeeping & caveats

Owner attention, outside CMS scope (review §6): a committed coordinator secret in eight titan-node bridge profiles and both manifests (its own runtime_ops.sh forbids exactly this — rotate on-host and strip); personal data in AntiRepoThreat's campaign reports; titan-observatory unversioned; the always-on preflight timer missing (uncommitted) broker coverage — the credential-holding components are the unwatched ones; imagetracer's license contradiction.

Addendum 6.2 — adversarially verified (SCMS-005): all 10 load-bearing claims confirmed with exact counts, 0 refuted. One defect the review missed: imagetracer's payload_hash is provably a constant — the hash function reads only keys the contract subset doesn't have, so the "contract hash" never varies. The two-tier design (P20) stands; adopt the design, not the code. Registered as UD-11.

Independent adversarial pass · scms-evidence-005

Addendum 6.1 — remediated later the same day: titan-observatory's log-endpoint shell-injection exposure is closed. shlex.quote() now wraps both the remote root and the validated path, with the line count clamped — two independent defenses where the review observed one. The unversioned finding stands, sharpened: the fix itself is unversioned working-tree state. Recommended upstream follow-up: git init + first commit, capturing the fix as titan-observatory's first recorded revision.

Verified against server.py · evidence scms-evidence-004a

Caveats: ACP is a tested MVP — production-grade contracts over a thin reference runtime, with the Railway gateway the one battle-complete component. open-knowledge is mature upstream OSS consumed here as an unversioned clone. titan-node's observation machinery is battle-derived while its declaration machinery outran enforcement — its own README says so. Roughly half of Tools carries no license. Single observed pass throughout.
