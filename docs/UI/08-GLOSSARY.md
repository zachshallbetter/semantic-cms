# Glossary

| Term | Plain-language meaning | Formal role |
|---|---|---|
| Canon | What the system says is true | Authoritative semantic state |
| Subject | What we are currently dealing with | Semantic center of a resolution |
| Surface | What matters here | Bounded contextual participation of semantic state |
| Purpose | Why we are looking | Declared intent of a surface |
| Lens | What we are considering | Restrictive/traversal rules over accessible state |
| Context | The situation around the request | Actor, task, session, time, selection, observations |
| Eligibility | Whether something may participate | Derived participation decision |
| Membership | What participates | Included semantic subjects and their basis |
| Priority | What matters more within this surface | Semantic emphasis, not visual size |
| Expression | How it may appear | Governed realization of semantic structure |
| Representation | What someone actually encounters | Delivered accessible artifact |
| Provenance | Where this came from | Declared, derived, observed, certified source class |
| Relation | How semantic objects are associated | Typed edge; non-causal by default |
| Observation | What was measured | Time-bounded recorded state |
| Qualification | Whether enough evidence exists | Evidence sufficiency decision |
| Promotion | Making the consequence real | Authorized publication/state transition |
| Consistency | How current this view is | Current, stale, conflicted, superseded, etc. |
| Withheld | Exists within disclosure policy but cannot participate fully | Access-bounded eligibility outcome |
| Resolution trace | Why this is here | Mechanical explanation of surface resolution |
| Fingerprint | What this resolved output depends on | Deterministic digest over observable dependencies and request inputs |
| Operation | What action may be exposed | Stable semantic action identity |
| Interaction | What may happen | Governed consequential process |
