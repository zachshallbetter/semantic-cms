## Traps — read these before writing code

**1. Verify against what is *staged*, not the working tree.** Twice, gates passed locally and failed
in CI because a required file was excluded by the user's global gitignore and never committed
(NR-scms-002, NR-scms-019). `scripts/check-tracked.py` now catches it. The working copy is not what
CI sees.

**2. "Gates pass" means a `gh run list` conclusion was read.** Never a local exit code. This project
made that claim falsely once (NR-scms-002) and it invalidated a day of assertions.

**3. Fix the class, not the instance.** Four defects this week recurred because a correction was
applied to the one site in front of me:
- substring matching on identities, fixed in one file and not the shared instrument (NR-scms-011)
- a third notification path that did not inherit a property the other two had (NR-scms-018)
- a validator hook fixed at one call site and left dangling at two others (NR-scms-020)
- **a prototype-chain lookup fixed in one table and reintroduced in another _in the same commit_**
  (NR-scms-021 — a live authorization bypass)

When a negative result names a class, sweep for every instance before closing it.

**4. Prefer unrepresentable over guarded.** NR-scms-021's fix is the model: canonical lookup tables
now have null prototypes, so an inherited key is simply absent. A guard is a rule every future caller
must remember, and this project has twice failed to remember one inside a single commit.

**5. A gate that cannot fail certifies nothing** — and one that cries wolf gets ignored. Every
`scripts/check-*.py` ships `--self-test` proving its detections fire. Two gates had to be *narrowed*
after reporting false positives on honest rows. Both matter.

**6. Assert the reason, not just the outcome.** A vector that checks "this was refused" without
checking *why* can pass while proving nothing — that is how the authority gate shipped broken
(NR-scms-005). Pair every refusal vector with a control that would fail if the system refused
everything.

**7. Node strips types; it does not check them.** A misplaced property is not a compile error. Runtime
validation or a vector is the only protection.

## Judgement calls a fresh agent should not silently reverse

- **Retroactive Ready predicates were refused.** 13 Done items carry a truthful *"no predicate"*
  marker instead. A predicate written after the work looks like governance and functions as
  decoration. Do not backfill them.
- **Attrs are open, slots are closed** (SCMS-076). The corpus carries genuine one-off attributes;
  closing the set would make types reject real content.
- **Required means definitional, not merely always-present.** `featured` appears on every project and
  is not required, because requiring it would encode the Medium import's shape as law.
- **Embargoes read no clock.** Visibility follows the *declared temporal coordinate*, which is what
  makes them replayable and scheduler-free. An absent coordinate fails closed.
- **The live channel decides nothing itself** — `deliver()` does. Do not compute a wave locally.
